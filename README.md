# Shop Project

This repository now separates the frontend and backend into two folders.

## Frontend

The `frontend` folder contains the original Ionic/Angular app. To run it:

```bash
cd frontend
npm install
npm start
```

## Backend

The `backend` folder provides a minimal Express server with `/login` and `/register` endpoints.
To run the server:

```bash
cd backend
npm install
npm start
```

Both projects can be started independently.
